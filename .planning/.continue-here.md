<context>

The design was deliberately simplified rather than replacing regexes with a
second verifier. The fact-operation prompt already performed semantic
comparison. The deleted marker layer merely vetoed or authorized that result
based on English cue words. Structural validation remains strict, while memory
retains both prior and current non-repeat facts. Relations such as
`superseded_prior_evidence_ids` are still recorded for audit and editor input.

This is logically non-destructive, not unbounded storage: a story retains a
bounded fact set and exposes a bounded baseline, so sufficiently old evidence
can still age out.
</context>
